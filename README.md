# Анализ поведения пользователей интернет-магазина

Анализ поведения пользователей интернет-магазина на основе данных о событиях (просмотр, добавление в корзину, покупка). Включает анализ воронки конверсии, временных паттернов активности, кластеризацию пользователей тремя методами, классификацию и реализацию пайплайна в виде класса WebTrafficAnalyzer.

---

## Описание

Задача: на основе данных о поведении пользователей на платформе электронной коммерции выявить паттерны активности, сегментировать аудиторию и построить классификатор для определения кластера новых пользователей.

В ходе работы:
- проведён анализ распределения событий по часам, дням недели и дням месяца
- построена воронка конверсии и проанализирована конверсия по категориям товаров
- сформированы поведенческие признаки для 611 800 пользователей
- выполнена кластеризация тремя методами: K-Means, Agglomerative Clustering, DBSCAN
- обучены и сравнены четыре классификатора: логистическая регрессия, дерево решений, случайный лес, XGBoost
- реализован класс WebTrafficAnalyzer — полный пайплайн от предобработки до классификации новых пользователей
- проведено сравнение паттернов за октябрь и ноябрь 2019 года

## Датасет

Датасет: **eCommerce behavior data from multi category store**
Ссылка: https://www.kaggle.com/datasets/mkechinov/ecommerce-behavior-data-from-multi-category-store

Датасет содержит данные о поведении пользователей на платформе электронной коммерции за октябрь и ноябрь 2019 года. В работе используется 5 000 000 строк из файла `2019-Oct.csv` и 2 000 000 строк из `2019-Nov.csv`.

После скачивания поместите файлы `2019-Oct.csv` и `2019-Nov.csv` в папку с ноутбуком и обновите пути к файлам в коде.

Основные поля:

| Поле | Описание |
|------|----------|
| `event_time` | Время события |
| `event_type` | Тип события: view, cart, purchase |
| `product_id` | Идентификатор товара |
| `category_code` | Категория товара |
| `brand` | Бренд товара |
| `price` | Цена товара |
| `user_id` | Идентификатор пользователя |
| `user_session` | Идентификатор сессии |

## Результаты

**Воронка конверсии (октябрь 2019, 5 млн событий):**

| Этап | Количество | Конверсия |
|------|-----------|-----------|
| Просмотры | 4 817 227 | — |
| Корзина | 97 452 | view→cart: 2.02% |
| Покупки | 85 321 | cart→purchase: 87.55% |
| Общая конверсия | — | 1.77% |

**Временные паттерны:**
- Пиковый час активности: 16:00
- Наиболее активный день: пятница
- Топ категория по покупкам: electronics

**Сравнение методов кластеризации** (выборка 50 000 пользователей):

| Метод | Силуэт | Davies-Bouldin | Время (сек) |
|-------|--------|----------------|-------------|
| K-Means | 0.589 | 1.188 | 0.78 |
| Agglomerative | 0.562 | 1.310 | 201.86 |
| DBSCAN | н/д* | 0.991 | 9.90 |

*DBSCAN нашёл 61 кластер, 3955 точек отнесены к шуму — силуэтный коэффициент не рассчитывался.

K-Means выбран как оптимальный метод: наилучший силуэт при минимальном времени работы.

**Кластеры пользователей (K-Means, k=3, октябрь):**

| Кластер | Пользователей | Доля | Среднее событий | Средняя конверсия | Средняя цена |
|---------|--------------|------|-----------------|-------------------|--------------|
| Случайные зрители | 554 710 | 90.7% | 5.7 | 0.003 | $332.51 |
| Исследователи | 26 112 | 4.3% | 57.8 | 0.010 | $266.19 |
| Активные покупатели | 30 978 | 5.1% | 11.1 | 0.386 | $351.89 |

**Сравнение методов классификации:**

| Метод | Accuracy | Precision | Recall | F1-score |
|-------|----------|-----------|--------|----------|
| Logistic Regression | 0.972 | 0.925 | 0.965 | 0.945 |
| Decision Tree | 0.893 | 0.922 | 0.625 | 0.745 |
| Random Forest | 0.974 | 0.947 | 0.950 | 0.949 |
| XGBoost | 0.992 | 0.976 | 0.991 | 0.984 |

Наилучший результат по всем метрикам показал XGBoost.

**Сравнение октябрь vs ноябрь (300 008 новых пользователей):**

| Кластер | Октябрь | Ноябрь |
|---------|---------|--------|
| Случайные зрители | 90.7% | 92.7% |
| Активные покупатели | 5.1% | 4.8% |
| Исследователи | 4.3% | 2.5% |

Распределение кластеров между месяцами стабильно — алгоритм корректно переносится на новые данные.
