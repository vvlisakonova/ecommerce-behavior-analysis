# ecommerce-behavior-analysis
Анализ поведения пользователей интернет-магазина на основе данных о событиях (просмотр, добавление в корзину, покупка). Включает анализ воронки конверсии, временных паттернов, кластеризацию пользователей тремя методами, классификацию и реализацию пайплайна в виде класса WebTrafficAnalyzer.
